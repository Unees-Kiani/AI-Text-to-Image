# AI Text-to-Image Generator

This is a simple AI Text-to-Image Generator made using Python, Gradio, and Hugging Face.

The user enters a text prompt and the AI generates an image based on that prompt.

## Features

- Generate images from text prompts
- Simple and easy-to-use interface
- Uses Hugging Face AI model
- Built with Python and Gradio

## Technologies Used

- Python
- Gradio
- Hugging Face
- FLUX.1-schnell

## How to Run

1. Install the required libraries.
2. Open the project folder in VS Code.
3. Run the following command:
